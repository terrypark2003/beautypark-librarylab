# 경쟁원 비교: 에디트의원 (범어동) vs 뷰티파크의원 범어점 — 2026.09

조사일 2026-09-05 · 출처 editclinic.co.kr (이벤트 게시판 wr_id 44·45·50·51·52, 해피아워·화목리프팅DAY 게시물). 이벤트 내용이 전부 이미지라 포스터에서 수치를 옮겨 적었다. **에디트 가격은 전부 부가세 별도 표기(=부가세 전)**, 우리 가격은 수가표 v77·요청서 D열(부가세 전). 단위 만원.
타원 이미지 원본은 repo에 넣지 않는다(저작권) — 수치와 URL만 남긴다.

## 0. 세 줄 요약

1. **에디트는 "쁘띠·중가 리프팅 콤보(30~50만) + 애드온 세트" 병원**이다. 리프테라2·슈링크·볼뉴머·온다에 조각주사(지방분해)·스킨보톡스·물광을 얹어 30~50만 티켓을 대량으로 판다. 우리는 같은 장비를 **단품 9~16만**으로 더 싸게 팔면서 "싸다"는 소구를 안 하고 있다.
2. **프리미엄(울쎄라·써마지·세르프)은 우리가 같거나 싸다.** 울쎄라 프라임 300샷 90만은 저쪽도 8월에 했던 가격이고, 400샷은 우리가 40만 낮다. 차이는 저쪽이 **정상가를 5~35% 높게 앵커링**해서 할인율이 커 보인다는 것뿐.
3. 우리가 진짜 비어 있는 자리는 **①스킨부스터 애드온 세트(리쥬란/리투오 + 스보 + 물광) ②30~45만 중가 RF 단품 ③점·문신 제거 같은 트래픽 훅 ④세르프 400/600·쥬베룩 볼륨 라인**이다. 나머지는 표기(포함 가치·회당 단가)만 고치면 된다.

## 1. 에디트의원 프로필

- 위치·타깃: 대구 범어동(우리와 같은 상권) · 홈페이지 문구 "쁘띠 집중 병원 / 필러·보톡스 맛집" · 피부과 전문의 원장 1인 단독 프로모션을 별도 라인으로 운영(원장 지정 불가 슬롯).
- 보유 장비(포스터 기준): 울쎄라피 프라임 · 써마지 · 세르프 · 온다 · 볼뉴머 · 슈링크 유니버스 · 리프테라2(라인·펜) · 피코플러스(26.08 도입) · 리쥬란 · 리즈네 · 리투오 · 쥬베룩(볼륨·아이·흉터) · 힐로웨이브 · LDM · 오메가라이트(LED).
- 우리에게 있고 저쪽 포스터에 없는 것: **써마지FLX 600샷 포함 구성 · 소프웨이브 · 쿨소닉 · 쿨페이즈 · 올타이트 · 토르RF · 인모드 · 엑셀V(홍조) · 골드PTT · 10주 프로그램(미백·홍조·여드름) · 바디 슬림**.
- 저쪽에 있고 우리 카탈로그·요청서에 없는 것: **볼뉴머 · 온다 · 조각주사 번들 · 얼굴전체 점·사마귀·흑자 제거 · 눈썹/아이라인 문신 제거 · 세르프 400/600 단품 · 쥬베룩 볼륨+아이 세트**.

## 4. 우리가 강한 것 / 약한 것

**강한 것**
- 프리미엄 장비 폭과 가격: 써마지FLX 600 포함 구성·소프웨이브·쿨소닉·올타이트·쿨페이즈까지 저쪽엔 없는 라인이 6개. 울쎄라·써마지·세르프는 정가 자체가 낮다.
- 진입가: 슈링크·리프테라2·LDM·아쿠아필·스킨보톡스 국산이 저쪽의 1/2~1/3. 화수목 라인업이 그대로 "범어동 최저 진입가"다.
- 프로그램형(10주 미백·홍조·여드름·색소 진단)과 바디 슬림 — 저쪽은 회차 메뉴만 있고 프로그램이 없다.
- 이벤트 운영 체계: 월별 테마 그룹 + 플친 3종 로테이션 + 장기 이벤트 + 반응 기록. 저쪽은 1년짜리 해피아워 1장 + 월 포스터.

**약한 것**
- 스킨부스터를 **단품**으로 판다. 저쪽은 전부 "+스킨보톡스+물광" 세트로 묶어 같은 가격에 더 준 것처럼 보인다(리투오 50만 = 우리 단품가와 동일).
- 30~45만 중가 리프팅 콤보가 없다. 우리 라인은 9~16만(화수목) 다음이 49만(쿨소닉)으로 건너뛴다.
- 트래픽 훅(점 제거 20만·문신 제거 10~15만)이 없다. 저쪽은 이걸로 첫 방문을 만들고 리프팅으로 올린다.
- 포함 항목(무통수액·핑크필·수액 2회·LDM)이 값으로 안 보인다 — 카탈로그 v2의 C 항목.
- 세르프 400/600 단품, 쥬베룩 볼륨 세트, 조각주사(아큐주사) 번들이 없다.

## 5. 대응안

### 즉시 (11~12월 요청서에 넣을 수 있는 것)
1. **「플러스 세트」 애드온 신설** — 얼굴전체 스킨보톡스(국산 8만) + 물광주사 2.5cc(9만) = 정가 17만 → **세트 12만**. 리쥬란·리투오·쥬베룩·힐로웨이브id 줄에 "+플러스 12만" 병기.
   - 리쥬란 힐러 2cc + 플러스 = 21 + 12 = **33만** (에디트 35만보다 2만 낮고, 정가 합산 38만 대비 13%)
   - 리투오 + 플러스 = **55만** (정가 합산 77만 → 29% · 9월 "리투오+스보 55만"과 같은 가격에 물광 추가) — 하루 한 자리 리투오 단품 50만은 그대로 두고 11월부터 세트로 전환
2. **아큐주사 사은 구조** — 화수목 리프팅에 "프리미엄 아큐주사 10cc 1회 포함"(6만 상당). 예: 슈링크 300샷 12만 → **슈링크 300샷 + 아큐주사 10cc 15만**(정가 22.5만 → 33%). 저쪽 "조각주사 FREE"의 우리 버전.
3. **얼굴전체 스킨보톡스(국산) 6.9만**을 12월 화수목 또는 다음 플친 교체 때 1줄 — 저쪽 24만의 1/3.5. 국산 제품명(코어톡스 여부)을 시술명에 적어 비교가 되게.
4. **중가 RF 1줄** — 쿨페이즈 300샷 정가 50만 → **39만**(12월 화수목 후보). 볼뉴머 300샷 39만과 같은 가격대에 놓는다.
5. 11월 울쎄라 300샷 90만 포스터에 **"무통수액 + 핑크필 포함(9만 상당)"** 을 반드시 표기 — 같은 90만이라도 포함이 다르다는 걸 보여 주는 게 유일한 차별점.

### 다음 분기 (카탈로그 v2·수가표 v78과 함께)
6. **흉터 3회권**: 흉터 올인원 2cc 3회 **79만** (v2 §4) — 저쪽 75만 대응.
7. **세르프 400 / 600샷 단품가** 신설(정가 확인 후 이벤트가 105 / 150만 선) — 세르프 이벤트를 11월 이후 이어갈 경우.
8. **쥬베룩 볼륨 4cc + 스킨부스터 2cc 세트** — 정가 65만 → 55만(15%).
9. **트래픽 훅 확인** — 수가표에 점·검버섯 제거, 문신 제거(피코슈어 가능) 단가가 있으면 "얼굴 점 N개 19.9만" 류 1줄 테스트. 없으면 골드PTT·오투덤(3.6만)이 그 역할.
10. **시간대 슬롯 실험** — 하루 한 자리를 "평일 12~16시 예약 시 2명"으로 넓히는 안. 가격은 안 내리고 슬롯만 늘린다.

### 하지 말 것
- **정상가 부풀리기**: 저쪽 3단 표기(정상가→할인가→더블할인)를 따라 우리 정상가를 올리지 않는다. 우리 정상가는 수가표 = 실제 판매가라 표시광고법상 안전하고, "정가부터 낮다"가 우리 메시지다.
- 타원 포스터의 "정상가"를 우리 정상가로 옮겨 적지 않는다(CLAUDE.md 가격 규칙 1).
- "맛집" 류 표현은 이미 쓰고 있으니 유지하되, "최저가·범어동 1등" 같은 최상급은 쓰지 않는다.
