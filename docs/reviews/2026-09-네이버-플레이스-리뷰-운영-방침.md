# 네이버 플레이스 리뷰 운영 방침 (2026-09-07 · 원장 결정)

배경: 실장이 신규 대행사(애드에이드)의 "네이버 리뷰 관리를 처음부터 업체가 맡는 게 어떤가"라는 제안을 원장에게 상의. 원장 결정을 정리한 것.

## 결론

**현행 유지. 업체 리뷰 진행은 한시적이며 지속하지 않는다. 리뷰 요청의 기본은 원내 루틴.**

| 항목 | 결정 |
| --- | --- |
| 업체 리뷰 진행 | **한시적** · 현재 **1건/일** · 지속하지 않음 (종료 시점은 추후 지정) |
| 업체에 전부 일임 | 하지 않음 — 중단 시 그 일을 직원이 처음부터 다시 해야 하므로, 지금부터 원내 루틴으로 유지 |
| 리뷰 답변(답글) | 현재 방식 그대로 유지 |
| 변경 | 변동 사항 생기면 이 문서 업데이트 |

## 이유

1. **의존 방지** — 업체에 일임하면 나중에 리뷰 진행을 중단할 때 직원이 처음부터 다시 해야 한다. 원내에서 습관으로 돌아가게 해 두는 게 맞다.
2. **한시적 운영** — 업체 진행은 1건/일로 제한된 임시 조치이고 계속 늘리거나 이어갈 계획이 없다. 이후는 자연 유입 + 원내 요청으로 유지.
3. **리스크** — 경쟁원 신고 이력이 있는 병원이라 리뷰는 실제 방문 고객 중심으로, 요청 시 특정 문구·별점 유도 금지, 답례는 소액 사은품 이내. 업체 진행을 한시적으로 두는 이유이기도 하다.

## 역할 분담

| 주체 | 맡는 것 |
| --- | --- |
| 원내 (당번팀) | 시술 후 만족 고객에게 리뷰 요청 · 당번 퇴근 체크리스트에 "네이버 리뷰 요청 ○건 / 등록 ○건" 한 줄로 매일 기록 · 주간 집계 |
| 업체 (애드에이드) | 현행 유지 — 리뷰 1건/일(한시적) · 답글 관리 · 악성/신고성 리뷰 모니터링 |

## 실장에게 보낸 회신 (원문 · 2026-09-07 확정)

> 네이버 리뷰는 실제 방문 고객 중심으로 운영하려고 합니다. 다만 매일 리뷰가 쌓이지는 않아서, 보조적으로 업체 도움을 받아 1건 정도/일로 진행하고 있어요. 이건 한시적인 거고 계속 이어갈 계획은 아닙니다.
>
> 그래서 처음부터 업체에 전부 맡기기보다는 **현재 방식 그대로** 가 주세요.
> - 업체: 지금처럼 리뷰 답글 관리 + 보조 1건/일
> - 원내: 시술 후 만족하신 고객께 리뷰 후기 작성 유도·독려 (당번 퇴근 체크리스트에 "리뷰 요청 ○건" 한 줄로 기록)
>
> 업체 진행을 나중에 중단해도 원내 독려는 계속되는 구조여야 하니, 이 부분 잘 부탁드립니다. 변동 사항 생기면 다시 공유할게요.

- 2026-09-07: 회신 원문을 "실제 방문 고객 중심 · 보조 1건/일 · 답글 + 원내 후기 작성 유도 독려" 프레임으로 교체.
