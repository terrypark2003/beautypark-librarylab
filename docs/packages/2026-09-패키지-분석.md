## 2. 구조 문제 4가지

1. **SKU 과다·중복** — 미백 6종(5회/10회 ×2 + 5주 + 10주 ×2 + 온리유), 흉터 올인원 5종(쥬베룩 용량만 다름),
   여드름·모공·흉터 4종이 서로 겹침. 선택지가 많으면 상담이 길어지고 구매는 줄어든다.
2. **묶음 혜택 논리 불일치** — 3%~29%가 규칙 없이 섞여 있어 "패키지 = 이득"이라는 학습이 안 됨.
3. **포함 항목이 문장 속에 묻힘** — 써마지 600샷의 수액 2회+LDM+관리 30%는 15만 상당인데 값이 안 보임.
   소프웨이브의 전용 쿨러·붓기관리도 마찬가지.
4. **의료광고 리스크 표현** — "모공소멸"(소멸=결과 보장), "온리유"(의미 불명). 카탈로그엔 괜찮아도 포스터·플친에 그대로 나가면 안 됨.

## 3. 개편 제안

### A. 묶음 혜택 규칙을 정하고 약한 것부터 손본다
- 규칙 제안: **100만 미만 15% · 100~300만 12~15% · 300만 이상 12% + exclusive 포함**
- 소프웨이브 아이 120만 → **110만** (11%) 또는 버츄 아이를 2회 기본 포함
- 생기동안 240만 → **220만** (12%) 또는 리투오 2회(4주 간격) 기본 포함
- 올인원 탄력 399만 → **369만** (10%) + 태반주사 3회로 상향
- 울써마지 900/1200 → 리투오 옵션가 40만 병기(세르프 관례) 또는 스킨보톡스 풀페이스 포함
- 프라임 600샷 → 600샷만 **3,300원/샷(198만)** 으로 내려 400→600 업그레이드 유인 생성. 가격 유지가 원칙이면 600샷에 스킨보톡스 풀페이스(국산) 기본 포함

### B. SKU를 줄이고 이름을 "결과 + 기간 + 등급"으로
- 미백 6종 → **3종**: 「톤업 스타터 5회」(토닝콤보) · 「미백 집중 10주」(프리미엄·플래티넘 통합, 플라필/엑소좀은 옵션) · 「색소 정밀 10주」(온리유 → 야누스 진단 3회를 이름에)
- 흉터 올인원 5종 → **1상품 + 용량표** (스킨부스터 2/3/4cc · 볼륨 2/3cc)
- 여드름·모공·흉터 4종 → **2×2 매트릭스**: (여드름 / 모공·흉터) × (베이직 4주 / 프리미엄 8~10주). 이름을 「모공·흉터 베이직 4주」「모공·흉터 프리미엄 8주」처럼 통일
- 바디 슬림 3종 → **「슬림 3회 — 팔뚝/종아리/복부 택1」 1상품** + 2부위 세트(예: 팔뚝+복부 106만 → 99만)
- 「모공소멸」 → **「모공 타이트닝 시그니처」**(의료광고 안전) · 「온리유」 → **「색소 정밀 진단 프로그램」**

### C. 포함 항목을 값으로 보여준다
- 써마지 600샷: "무통수액 + 비스포크 수액 2회 + LDM 1회 = **약 15만 상당 포함**" (수액 단가는 수가표 항노화 페이지로 확정)
- 소프웨이브: "시술 전용 쿨러 + 붓기 관리(5만) 포함"
- 프라임 리커버리: "무통수액 + 핑크필(9만) 포함 — 핑크필은 1~2주 내 별도 내원"
- 모든 n회권·주차 프로그램에 **회당/주당 단가** 병기 (예: 미백 집중 10주 · 주당 10.5만)

### D. 시즌 로테이션으로 "이달의 패키지"를 만든다
| 시즌 | 밀 패키지 | 이유 |

| 11~2월 | 홍조 2종 | 실내외 온도차 · 연말 모임 "붉은 얼굴" 고민 |

### E. 상담·포스터 표기
- 10주 프로그램의 주차 표는 원내 상담지용. 포스터·플친에는 **핵심 3요소 + "상세 구성은 상담 시"**
- "비만약 처방" 같은 처방 문구는 대외 광고에서 제외
