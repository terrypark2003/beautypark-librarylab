# 원내 디스플레이 영상 만들기 (대기실 TV · 토스 단말기)

에이전시가 **영상 제작은 업무 범위 밖**이라고 회신했고(2026-09 카톡), 대신 **1920×1080으로 리사이징한 이미지**를 주기로 했다.
그 이미지를 받아서 원내에서 재생할 mp4/3gp를 **직접 만든다**.

## 만드는 법

```bash
pip install imageio-ffmpeg            # ffmpeg 없을 때 1회 (정적 빌드 내장)
python3 tools/build_display_video.py <이미지폴더> "<출력이름>" [--sec 6] [--fade 0.8] [--only mp4|3gp]

# 예: 10월 포스터 8장 → mp4 + 3gp
python3 tools/build_display_video.py ~/uploads/10월포스터 "10 bp 디스플레이 영상"
```

- 이미지는 **파일명 순서**대로 재생된다. `01_`, `02_` 처럼 번호를 붙여 순서를 정한다.
- 1920×1080이 아닌 이미지(세로형 등)는 비율을 지킨 채 검은 여백으로 채운다 — **잘리지 않는다**.
- 무음이다. 원내 디스플레이는 보통 음소거라 음악을 넣지 않았다.

## 출력 스펙 (검증 완료)

| 포맷 | 코덱 | 해상도 | fps | 8장·장당 6초 기준 용량 | 용도 |
| --- | --- | --- | ---: | ---: | --- |
| mp4 | H.264 High @L4.0, yuv420p, faststart | 1920×1080 | 30 | 약 1.1 MB | **기본** — 대기실 TV·USB 재생 |
| 3gp | MPEG-4 Part 2 (Simple Profile), yuv420p | 640×360 | 30 | 약 2.4 MB | 구형 디스플레이 호환용 |

- 8장 기준 인코딩 **약 30초**. 장수에 비례한다.
- 기존 원내 파일(`09 bp 디스플레이 영상.3gp`)은 **132.81 MB**였다. 같은 내용이면 위 설정이 훨씬 가볍다.
  용량이 크게 다르면 원본이 더 높은 해상도·비트레이트였을 수 있으니 기기 스펙을 확인한다.

## 기본값을 바꿀 때

| 옵션 | 기본 | 언제 바꾸나 |
| --- | ---: | --- |
| `--sec` | 6 | 글자가 많은 포스터는 8초, 짧은 문구는 4~5초 |
| `--fade` | 0.8 | 0으로 두면 즉시 전환(딱딱함), 1.5면 느긋함. `--sec`보다 작아야 함 |
| `--only` | (둘 다) | 기기가 mp4를 읽으면 `--only mp4` |

3gp 해상도는 `tools/build_display_video.py`의 `GP_W, GP_H`에서 바꾼다.

## 알아둘 것 (삽질 기록)

- **`fps`는 필터 체인 맨 뒤에 둬야 한다.** `fps` 뒤에 `setpts`를 붙이면 xfade가 프레임레이트를 못 읽어
  `The inputs needs to be a constant frame rate; current rate of 1/0 is invalid`로 죽는다.
- **`-filter_complex`와 `-vf`를 같이 못 쓴다.** 3gp 해상도 축소도 그래프 안에서 처리한다.
- 정적 ffmpeg 빌드(imageio-ffmpeg)에는 **`drawtext` 필터와 `ffprobe`가 없다.** 자막이 필요하면 이미지에 넣어 오고,
  결과 확인은 `ffmpeg -i <파일>`로 한다.
- 컨테이너가 초기화되면 ffmpeg과 업로드 파일이 사라진다. `pip install imageio-ffmpeg`부터 다시 한다.

## 원내 확인 필요

1. **디스플레이 기기가 mp4를 읽는지.** 읽으면 3gp는 만들 필요가 없다.
2. **기존 `09 bp 디스플레이 영상.3gp`의 해상도·비트레이트.** 링크(Send Anywhere)가 만료돼 확인하지 못했다.
   파일을 다시 받으면 스펙을 그대로 맞출 수 있다.
3. 장당 노출 시간과 전환 효과 취향(현재 6초·0.8초 페이드).
