## 왜 울쎄라인가

- 10.31에 세르프 맛집·소프웨이브 페스타·레티젠 아이가 모두 끝나 **11월 리프팅 앵커가 빈다** → 울쎄라가 그 자리를 잇는다
- 연말 모임 시즌(D-30) + 자외선 약한 시기 = 리프팅 최성수기
- 울쎄라피 프라임 300샷 리커버리 프로그램 정상가 **119만**(수가표 v77, 무통수액·핑크필 포함) → **90만 = 24% 할인**
- 참고 이력: 구형 울쎄라 300샷 단품 이벤트가 85만(25.08) · 프라임 300샷 런칭가 119만(25.11~26.2, 지금은 정가가 됨)
  → 프라임 기준 **역대 최저가**. 트랜스듀서 원가 대비 마진 확인 필요
- 10월 하루 한 자리 프라임 400샷 119만(샷당 2,975원)과 300샷 90만(샷당 3,000원)은 단가가 맞아 충돌 없음

## 대표 확인 필요

1. **90만이 "울쎄라피 프라임" 기준인지** — 정상가 119만(리커버리 프로그램 포함)을 기준으로 잡았다. 구형 울쎄라나 리커버리 미포함이면 정상가·구성 수정
2. **프라임 300샷 90만 마진** — 프라임 기준 역대 최저가. 트랜스듀서 원가 확인
3. **운영 기간** — 11월 한 달 vs 11~12월 두 달(제안). 두 달이면 12월 요청서에서 연장 표기
4. 울쎄라 콤보 2종(스킨보톡스·올타이트)과 옵션가 리투오는 제안 — 빼거나 바꿔도 됨
5. 블프 남성 제모 라인은 수가표 제모 페이지 미확인이라 보류 (수가표 있으면 추가)
