# 세이프닥 특가전 가격 검토 (2026-09-16)

검토 대상: 세이프닥 특가전 3개 프로그램(레이저 토닝 5회 / 1회 / 5회+리투오).
기준: 수가표 v77(부가세 전) · `docs/packages/2026-09-패키지-카탈로그.md`(부가세 포함) · `tools/plans/2026-10.json` · `docs/competitors/2026-09-에디트의원-비교.md`.
상태: **검토 의견(대표 결정 전)** — 가격을 바꾸지는 않았다.

## 0. 결론 세 줄

1. **할인율 자체는 문제없다.** P1 20.4% · P3 19.0%로 우리 10월 이벤트 평균 27%보다 오히려 보수적이다. 회당 단가도 에디트의원 토닝(회당 9만 전)보다 27% 싸서 경쟁력이 있다.
2. **문제는 가격이 아니라 "정가" 표기와 사다리다.** 1회 정가 ×5(61.2만)와 5회 정가(45.1만)가 어긋나고, 5회 정가 45.1만은 **원내 정가 49.5만보다 낮다**. 즉 표기된 정가가 실제 원내 판매가가 아니다.
3. **1회 7.9만과 5회 회당 7.18만의 차이가 9%뿐**이라 5회를 살 이유가 약하다. 게다가 7.9만은 우리 토닝 단품 정가(8.25만 포함)보다도 낮다.

## 1. 가격 해부 (부가세 포함 표기로 판단)

| 프로그램 | 정가 | 우대가 | 특가 | 특가 할인 |
| --- | ---: | ---: | ---: | ---: |
| P1 토닝 5회 | 451,000 | 399,000 | 359,000 | 20.4% |
| P2 토닝 1회 | 122,300 | 109,000 | 79,000 | 35.4% |
| P3 토닝 5회 + 리투오 1회 | 1,111,000 | 1,060,000 | 900,000 | 19.0% |

**부가세 포함가가 맞다**는 근거: `P3 정가 − P1 정가 = 660,000`이고, 이는 수가표 리투오 7/8cc **600,000 전 × 1.1**과 정확히 일치한다. P1 정가 451,000 ÷ 1.1 = 410,000, P3 1,111,000 ÷ 1.1 = 1,010,000으로 둘 다 정수로 떨어진다.
⚠️ **P2만 예외** — 122,300 ÷ 1.1 = 111,181.8로 떨어지지 않는다. P2 정가만 산정 기준이 다르다.

**구성 역산으로 확인한 것**: P1 정가 회당 = 82,000 전. 우리 10월 「토닝+엑셀V 제네시스+선택관리」 정상가 회당 145,000 전과의 차이는 63,000 전으로, 수가표 엑셀V 제네시스 70,000 전과 맞아떨어진다. → **세이프닥 구성 = 우리 토닝 콤보에서 제네시스를 뺀 것**이다. 단가 산정 자체는 우리 수가표와 정합적이다.

## 2. 문제 4가지

### ① 정가 사다리가 어긋난다 (우리 가격 규칙 위반)

CLAUDE.md 가격 규칙 2: *n회권 정상가 = 1회 정상가 × n으로 반드시 검산.*

| 검산 | 값 |
| --- | ---: |
| P2 정가 × 5 | 611,500 |
| P1 정가 (표기) | 451,000 |
| 5회 정가에 이미 내장된 선할인 | **26.2%** |

정가에 26% 할인을 숨겨 놓고 거기서 다시 20% 특가를 붙이는 구조다. 실질 할인은 41%인데 화면에는 20%로 보인다.

### ② 표기 정가가 원내 정가보다 낮다

| 구분 | 부가세 포함 |
| --- | ---: |
| 원내 카탈로그 「피코슈어토닝 + 모델링팩 5회 + 줌패스 1회」 | 495,000 |
| 세이프닥 P1 표기 정가 | 451,000 |

44,000원 낮다. "정가"는 실제 원내 판매가여야 표시광고법상 안전하다. 구성이 완전히 같지는 않으므로(선택관리 = 모델링팩 여부 확인 필요) 단정은 못 하지만, **원내에 없는 숫자를 정가로 쓰고 있는 것은 맞다**.

### ③ 1회와 5회 사이에 업그레이드 유인이 없다

| | 부가세 포함 |
| --- | ---: |
| P2 1회 특가 | 79,000 |
| P1 5회 특가 회당 | 71,800 |
| 차이 | **7,200원 (9.1%)** |

1회 체험이 5회 패키지를 잠식한다. 게다가 79,000은 우리 토닝 단품 정상가 75,000 전(= **82,500 포함**)보다 3,500원 낮다. 선택관리·정밀촬영·원장 상담까지 얹은 값이라 1회만 팔리면 남는 게 없다.

### ④ 10월 원내 이벤트와 충돌한다

| | 회차 | 부가세 포함 |
| --- | ---: | ---: |
| 10월 원내 「가을 톤 리셋」 토닝+제네시스+선택관리 | 3회 | 363,000 |
| 세이프닥 P1 | **5회** | 359,000 |

제네시스 포함 여부가 다르지만, 고객 눈에는 "원내에서 3회에 36.3만, 세이프닥에서 5회에 35.9만"으로 보인다. **원내 고객이 손해 보는 그림**이다.

또 P3의 리투오 실질 단가는 **491,818 전**으로, 우리 10월 「하루 한 자리(매일 선착순 1명)」 리투오 500,000 전보다 낮다. 가장 희소한 슬롯의 가격이 세이프닥에서 상시로 풀리면 희소성 명분이 깨진다.

| 프로그램 | 항목 | 현재 | 제안 | 근거 |
| --- | --- | ---: | ---: | --- |
| P1 | 정가 | 451,000 | **495,000** | 원내 카탈로그 정가와 일치 → 할인 27.5%로 10월 평균과 정렬 |
| P1 | 특가 | 359,000 | 유지 | 회당 65,273 전, 에디트 90,000 전 대비 27% 우위 |

우대가는 정가·특가를 확정한 뒤 그 사이에서 다시 잡으면 된다.

**10월 충돌 해소** — 셋 중 택1:
- ㉮ 세이프닥 노출을 10월 「가을 톤 리셋」 종료 후로 미룬다
- ㉯ 세이프닥 상품명에 「제네시스 미포함」을 명시하고, 원내 3회권은 제네시스 포함을 부각한다
- ㉰ 원내 3회권을 5회권으로 맞춰 회차 비교가 성립하게 한다

## 4. 확인 필요

1. **선택관리 = 모델링팩인지** — 원내 카탈로그 「토닝+모델링팩 5회+줌패스」와 같은 구성이면 정가 495,000을 그대로 쓰면 되고, 다르면 별도 정가를 세워야 한다.
2. **레이저 토닝의 장비** — 피코슈어인지 헐리우드인지. 수가표 단가(둘 다 75,000 전)는 같지만 상품명 표기가 달라진다.
3. **시술 전 피부 정밀 촬영** = 야누스 촬영인지, 유료 항목인지. P1 정가 410,000 전이 82,000 × 5와 정확히 같아 **촬영은 무상 포함**으로 계산돼 있다. 반면 P2 정가에는 촬영 값이 얹혀 있는 것으로 보인다(111,182 전 − 82,000 = 29,182 전).
4. **세이프닥 수수료율** — 특가에서 수수료를 뺀 실수령액 기준으로 마진을 다시 봐야 한다. 이 검토에는 수수료가 반영돼 있지 않다.
5. **유효기간 6개월 · 본인 한정** 조건은 그대로 유지 권장. 양도 가능으로 열면 재판매가 생긴다.
